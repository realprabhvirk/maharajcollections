Maharaj Collections: a static wall art site in plain HTML, CSS and JS (no build step), with products in `products.js` and images in `/images`.
Run it by opening `index.html` in a browser, or drop the folder on any static host (it deploys on Netlify, forms use Netlify Forms).
Rule: no em dashes or en dashes anywhere in the site (copy, code, comments), use a hyphen or the word "to".
